# SolixBar 0.6.1

## Deutsch

- Die Homepage weist direkt bei der Sprachauswahl darauf hin, dass Arabisch derzeit nicht enthalten ist.
- Eine hochwertige arabische Fassung benoetigt neben der Uebersetzung eine vollstaendig gepruefte Rechts-nach-links-Darstellung und wird deshalb nicht als reine Textuebersetzung angeboten.
- App-Funktionen, Messwerte, Aktualisierung, Layout und die vorhandenen 20 Uebersetzungen bleiben unveraendert.

## English

- The homepage now states directly beside the language selection that Arabic is not currently included.
- A high-quality Arabic version requires a fully verified right-to-left layout in addition to translated text and is therefore not offered as a text-only translation.
- App features, readings, refresh behavior, layout, and the existing 20 translations remain unchanged.
